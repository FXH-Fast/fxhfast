# FXHFast

FXHFast 是一个由志愿者独立创建和维护的数字货币行情展示站，提供币种行情、币种排行、交易所排行及相关市场信息。

网站地址：

[https://fxhfast.com/zh-cn/](https://fxhfast.com/zh-cn/)

## 项目说明

FXHFast 独立开发和维护，不属于非小号官方网站。

本站使用非小号 API 或相关数据接口获取行情数据。API 的使用不代表本站与非小号存在合作、授权或官方背书关系。

## 数据与免责声明

本站展示的行情数据仅供信息参考，不构成投资、交易或其他金融建议。加密货币市场波动较大，使用者应自行核实信息并评估风险。

数据可能因接口、网络或服务状态变化而出现延迟或暂时不可用。

## 维护方式

本项目由志愿者维护，网站功能、数据接口和页面内容会根据实际情况进行更新。
